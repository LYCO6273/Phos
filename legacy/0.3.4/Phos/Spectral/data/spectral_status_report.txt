光谱迁移现状档案（冻结基线）
日期：2026-09-01
状态：光谱迁移深入优化暂时冻结。本项目态度：线性问题（响应曲线、
反转校色、锚点校正）定量准确；复杂问题（光谱迁移、rms、邻域效应、
光晕）定性正确 + 数量级正确 + 观感合理。

—— 结论 ——
光谱迁移保持 uniform 统计映射（光谱先验等权最小二乘，3×4 线性矩阵，
白场归一 + 偏置清零），作为"模拟拍摄"假设的正确地基。
曾实验 density / density_err 加权映射（A/B），双轴报告证明其在常见色上
负收益（Gold 0 胜 3 负 / 5213 2 胜 3 负 / Provia 2 胜 4 负），已放弃。

—— 双轴评价方法 ——
把"偏色方向"分解为两个正交轴（显示 RGB 比例，档位 = log2 倍率）：
  G/B 轴：>0 = 青化（绿层相对蓝层上升），<0 = 紫/蓝化
  R/G 轴：>0 = 黄/红化（红层相对绿层上升），<0 = 青化
净 hue 是两轴效应的净值，不能单看（曾导致绿系方向误判）。

—— 已知系统性缺口（uniform 现状，三卷一致） ——
1. 绿/青系 R/G 轴偏低 1.4~2.2 档：模拟红层对 560-650nm 红尾的抓取
   只有真实胶片的约 1/4（色卡 green/bluish green/cyan 最明显）。
   真实胶片绿系偏黄绿（红层抓红尾），模拟偏青——方向相反。
2. 蓝紫/紫系偏品红不足（净 hue -6~-17°）：blue flower/purple 的
   深红尾巴被红层抓取不足。
3. 蓝色系：真实胶片对纯蓝光（420-450nm）偏青（蓝绿层重叠），对带
   红尾的蓝偏紫；模拟把两力配比搞错（blue sky/cyan 紫化不足、
   blue 紫化过头）。
4. 肤色/红/橙/黄：双轴偏移 <0.5 档，拟合良好，不要动。
5. 中性 6 块：真实胶片微暖（a*/b* +1~+3），模拟几乎纯中性。
