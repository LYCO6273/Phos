# 胶片模拟模型开发规范（0.3.3 三段式）

> 本文档定义从技术文档（datasheet）到可运行胶片模型的**完整开发规范**，
> 同时是当前处理管线的**权威说明**（与代码逐条对齐）。
> 覆盖三种胶片类型：**黑白负片、彩色负片、彩色正片**。
>
> 三条原则：
> 1. **数据从文档来**——每个参数都要有 datasheet / 实测来源；
> 2. **缺失找同级代理**——找不到就用定位最接近的胶片顶替，并记录来源与可信度；
> 3. **所有轴统一到绝对物理标尺**——曝光、波长、空间频率全部锚定到统一坐标。
>
> 另有一条贯穿性不变式：**黑点 / 中灰点 / 白点三个锚点在
> “原片 → 0-1 输入 → 扫描输出”三个阶段始终统一**（见 §1.4、§3.3）。

---

## 0. 总体架构（三段式）

```
原片字节（DNG / JPEG / PNG）
  │
  ▼ 第一段  Input（原片解析）
  │   原片 → 镜头光学修正 → 曝光/灰点标定 → 相对中灰 E_mid 三通道
  ▼ 第二段  Films（胶片模拟）
  │   光谱输入 → PSF 光扩散 → 对数曝光 → 特性曲线 →
  │   密度域颗粒 → 染料堆叠+客观扫描（彩负/正片）或直接密度（黑白）
  ▼ 第三段  Scanner（扫描仪渲染）
  │   三锚点 PCHIP 校正（黑/灰/白 → 0 / sRGB 118 / 255）→ 风格对比度 → 成片
  ▼
uint8 成片（JPEG，质量 100）／可选 16bit 原片扫描（TIFF）
```

模块索引：

| 段 | 文件 | 职责 |
|---|---|---|
| 一 | `Input/decode.py` | 统一入口，按扩展名分发 |
| 一 | `Input/raw.py` | DNG：rawpy 线性解码、IFD0 标签（BE/OpcodeList3）、灰点归一化、标准化、负值钳制 |
| 一 | `Input/jpeg.py` | JPEG/PNG：sRGB EOTF + 数转胶归一化 |
| 一 | `Input/optical.py` | DNG OpcodeList3 镜头光学修正（GainMap / FixVignetteRadial） |
| 二 | `Films/<name>/<name>.py` | 模型主文件：管线 + 曝光/锚点常量 |
| 二 | `Films/<name>/<name>_data.py` | 数据加载器（只读 npz，带缓存 + 均匀网格标记） |
| 二 | `Spectral/reconstruct.py` | 光谱重建：合成光谱训练 RGB→层曝光映射矩阵 |
| 二 | `Spectral/cie_data.py` | CIE 1931 2°、D65、sRGB↔XYZ 共享常量 |
| 三 | `Scanner/scanner.py` | 三锚点 PCHIP、风格对比度、16bit 导出入口 |

## 1. 第一段：输入契约与实现

### 1.1 统一语义：相对中灰 E_mid

所有图源经第一段后统一为同一物理语义：

- **中灰（18% 灰 / 相机定义灰点）= E_mid = 1.0**
- 工作轴：`stop = log2(E_mid)`（2 为底，中灰恒在 stop 0）
- 允许 `E_mid > 1`（过曝余量，胶片肩部需要）
- 传感器饱和（DNG，无 BE 时）≈ `7.80`，即中灰上方 `+2.97` 档

灰点物理依据（ISO 12232）：

```
H_sat  = 78 / ISO          （饱和速度）
H_gray = 10 / ISO          （SOS 标准输出灵敏度，内含 1/2 档高光余量）
灰点相对饱和 = 10/78 = 0.1282 = 18%/√2   （+2.97 档，与 ISO 无关，ISO 相消）
```

> 注意：`12.5/78 = 0.1603` 是把测光常数 K 误当成焦点平面灰点得到的
> 流传较广的错误比值（会偏暗 0.32 EV），**不要使用**。

### 1.2 DNG 路径（`Input/raw.py`）

处理顺序（严格按此）：

1. **线性解码**：rawpy `postprocess(gamma=(1,1), no_auto_bright=True,
   use_camera_wb=True, bright=1.0, output_bps=16)`
   → `E_sat = 像素/65535`，其中 `1.0 = 传感器饱和 / 白电平`（黑电平已扣除）。
2. **IFD0 元数据**：纯 Python 解析（支持 II/MM 字节序）：
   - `BaselineExposure`（0xC62A）+ `BaselineExposureOffset`（0xC7A5）
     → 总 EV（缺失为 0）；
   - `OpcodeList3`（0xC74E）→ 镜头光学修正参数。
3. **镜头光学修正**（`Input/optical.py`，默认开）：按 DNG 规范在
   “去马赛克后的线性参考值”上执行 OpcodeList3：
   - `GainMap`（ID 9）：子采样 2D 浮点增益表，双线性插值 + 网格外边缘
     复制，按 `bounds` / `rowpitch` / `colpitch` 限定作用像素，逐平面乘；
   - `FixVignetteRadial`（ID 3）：`g = 1 + k₀r² + k₁r⁴ + k₂r⁶ + k₃r⁸ + k₄r¹⁰`，
     r 为到光心的归一化距离；
   - `WarpRectilinear / WarpFisheye / WarpRectilinear2`（ID 1/2/14）：
     畸变与横向色差，**尚未实现**，遇到时跳过（当前样张均无）。
   - 与规范不同：opcode 结果**不 clip 到 [0,1]**，保留过曝余量（乘法修正不受影响）。
4. **灰点归一化 + 相机曝光定义**：
   ```
   E_mid = E_sat / 0.1282 × 2^BaselineExposure
   ```
   这样“相机认为的正确曝光”（ACR/预览 Exposure=0 的语义）恒落在 `E_mid = 1`。
5. **标准化尺寸**：短边统一到 3024（缩小 INTER_AREA，放大 LANCZOS4，偶数尺寸）。
6. **负值钳制**：重采样振铃会在黑位附近产生负的线性光（物理上不存在），
   统一按黑点钳制到 0。

### 1.3 JPEG / PNG 路径（`Input/jpeg.py`，数转胶）

```
像素 /255 → sRGB EOTF（分段 12.92 / 2.4 幂）→ E_mid = 线性值 / 0.18
```

- 语义：像素值 = 场景反射率（数转胶假设），显示白（255）= 反射率 1.0；
- 中灰 sRGB 118 → 线性 0.18 → E_mid ≈ 1.0；
- 白场 255 → E_mid = 5.56，比扫描白锚（6.24）低 **0.17 档**，因此 JPEG 纯白
  经胶片后输出 245–252 而非 255——这是胶片肩部给“场景白之上”留的真实余量
  （DNG 饱和点才对应输出纯白），属于设计语义，不是断链；
- 标准化短边 3024（与 DNG 路径统一）。

### 1.4 三锚点定义（贯穿三阶段的不变式）

| 阶段 | 黑点 | 中灰点 | 白点 |
|---|---|---|---|
| 原片（DNG） | raw 黑电平 | 灰点 raw 值 = 0.1282×2^BE × 白电平 | 白电平（传感器饱和） |
| 0-1 输入（E_mid） | 0 | 1 | 7.80×2^BE |
| 扫描输出（uint8） | 0 | sRGB 118（0.4627） | 255 |

JPEG 路径同轴：0 / sRGB 118 / 255 → E_mid 0 / ≈1 / 5.56 → 输出 0 / 118 / 245–252。

动态范围语义：

- 输入动态范围（DNG 约 10–12 档、JPEG 8bit 极限约 8 档）在 stop 轴上守恒：
  灰点上方恒 2.97 档（DNG 饱和）/ 2.47 档（JPEG 白场），下方随输入噪声底；
- **胶片的趾部/肩部压缩输入两端**——高光柔化与阴影压缩的物理来源；
- 不做对称化 / 缩放；
- 过曝（E>1）：特性曲线肩部柔化为主，反转侧白端截断收口；
  完整过曝梯度走 16bit 原片导出（scan 为密度/透光率 HDR，不 clip）。

## 2. 第二段：胶片模拟公共管线（固定顺序，不可乱）

第二段输入 `(E_mid_R, E_mid_G, E_mid_B)`，输出：

- 彩负 / 彩正：`scan`（float32，透光率语义，正负像由曲线斜率决定）；
- 黑白：`density`（float32，直接密度域）。

### 2.1 光谱输入（光谱重建，唯一路径）

`Spectral/reconstruct.py`：sRGB 是“场景光谱 → 标准观察者”的 3 维投影，
胶片三层曝光是同一光谱“→ 乳剂层灵敏度”的 3 维投影。直接重建完整光谱是
病态问题（3 维→61 维），改为在物理光谱先验下学习统计映射：

```
E = [R, G, B, 1] · M_film
```

- 训练数据：`N=3000` 条合成反射光谱（1–4 个宽高斯峰叠加 + 红色先验 +
  蓝色先验 + 轻微起伏，截断到 [0,1]），固定种子 42，可复现；
- 每条光谱同时投影到 CIE 1931 2°（输入侧 sRGB）与胶片灵敏度（输出侧曝光）；
- 回归后**偏置行清零**（无光=黑，防止暗部红雾），**白场归一化**
  （(1,1,1) → 每层曝光 ≈1）；
- 矩阵：彩负/彩正 (4,3)（列 B/G/R 层），黑白 (4,1)；
- 缓存：`Data/cache/spectral_reconstruct.npz`（带版本指纹，版本 5）；
- 独立验证：`Spectral/data/colorchecker_babel.csv` 24 色真实光谱，
  不参与训练，曝光 MAE < 0.04 视为通过；
- 注册新胶片：`Spectral/migrate.py` + `reconstruct.py` 的 `_SENSITIVITY_CSV`。

### 2.2 PSF 光扩散（MTF 频域拟合 → 空间核）

模型：核心高斯 + K0 扩散晕 − 邻界高斯

```
MTF(f) = w_c·exp(-2π²σc²f²) + w_d/(1+(2πδf)²) − w_a·exp(-2π²σa²f²)
```

- 拟合：在物理参数范围内网格搜索 + 非负最小二乘（σc/δ/σa 单位 mm），
  单层或按层（MTF 有分层数据时逐层拟合）；
- 空间核：`w_c·g(σc) + (w_d/2πδ²)·K0(r/δ) − w_a·g(σa)`，归一化 DC=1；
- 运行时分解为可分离高斯堆（`cv2.GaussianBlur` 快速卷积），曝光量只影响
  强度线性增益，与卷积线性可交换；
- `PX_PER_MM = 100`（模拟扫描分辨率 100 px/mm ≈ 2540 dpi）；
- 缓存：`Films/<name>/data/psf_params_<name>.npz`，带 MTF 指纹自动失效。

### 2.3 对数曝光工作区

```
logH = log10(E_mid) + REF_LOG_E + exposure_offset·log10(2)
```

- `E_mid` 先钳到 `E_FLOOR = 1e-4`（防 log(0)，暗部统一落到特性曲线趾端）；
- `REF_LOG_E`：胶片侧数据表灰点锚（见 §6）；
- `exposure_offset`：曝光补偿（档），UI 滑块，默认 0。

### 2.4 特性曲线查表

- 查表轴统一为**严格均匀网格**（dx=0.05，float64），运行时走免二分的
  线性插值 `_interp_uniform`（两端夹紧）；非均匀网格回退 `np.interp` 兜底；
- 层映射：R=红感光/青染料、G=绿感光/品红染料、B=蓝感光/黄染料；
- 正片曲线为**负斜率**（高曝光 → 低密度 → D-min），负片为正斜率；
- `D_min / D_max` = 网格两端值（外推即夹紧，不产生超范围外推）。

### 2.5 密度域颗粒

```
白噪声 → Cholesky 层间相关（ρ=0.5）→ sign·|z|^p（p=2，χ²₁ 散粒幅度）
→ 可分离高斯组合赋形（σ₁=0.7px，unsharp 0.8@σ₂=2.0px）
→ 可选 2x 超采样（高分辨率生成后块平均降采样）
→ 48µm 孔径闭环标定（Monte Carlo，scale=1/σ，固定种子 12345）
```

- 颗粒在**密度域**叠加：`D += n·σ_D`，σ_D 由颗粒度曲线调制；
- 彩负/彩正：σ_D 按 **logH** 查表（颗粒度曲线 X 轴=对数曝光）；
- 黑白：σ_D 按**净密度**查表（黑白 rms 曲线 X 轴=密度，物理上更直接）；
- 标定缓存：`Films/<name>/data/grain_calib_<name>_ss{1,2}.npz`，
  参数指纹（ss/成形/核/种子/孔径/分辨率）变化自动失效；
- `grain_ss`：1=1x 不超采样，2=2x（默认 2）。1x **仍有颗粒**，只是不超采样。

### 2.6 染料堆叠 + 客观 CIE-RGB 扫描（彩负/彩正）

```
D(λ) = (D_B−Dmin_B)·s_y(λ) + (D_G−Dmin_G)·s_m(λ) + (D_R−Dmin_R)·s_c(λ) + D_min(λ)
T(λ) = 10^(−D(λ))
XYZ  = Σ_λ T(λ)·D65(λ)·CMF(λ)·Δλ        （权重 Y 归一化到 1）
scan = XYZ @ XYZ_to_sRGB.T（线性 sRGB，负值截断到 0）
```

- 扫描权重预计算缓存（`k·D65·CMF·Δλ`，Y 归一化）；
- 分块执行（512×512）控制内存；
- 对彩负，`scan` 是负像透光率；对彩正，`scan` 即正像透光率（无需反转）。

### 2.7 黑白：无染料堆叠

黑白直接输出特性曲线密度（单通道），第三段在密度域三锚点反转；
不需要染料光谱、不需要 CIE 扫描（黑白没有色罩问题）。

## 3. 第三段：扫描仪渲染（`Scanner/scanner.py`）

### 3.1 三锚点 PCHIP 校正

每通道以三个密度锚点构成平滑校正曲线（PS 拉曲线式）：

```
黑（0,0,0 输入）  → 输出 0
灰（E_mid=1）     → 输出 sRGB 118（0.4627）
白（E_mid=6.24）  → 输出 1.0（255）
```

- 插值：Fritsch–Carlson 单调保形三次（PCHIP 同款），纯 numpy；
- 锚点按密度自动排序（正片 black > gray > white，负片相反），数学统一；
- **边界截断**：密度超出锚点范围直接取端点输出（黑/白），
  防止三次外推产生异常值（色相硬跳变/紫块的根因，已按此修复）；
- 中间影调只受三点约束，顺其自然（保留胶片的趾/肩性格）。

### 3.2 风格对比度（风格层，非物理层）

```
u  = 2·(pos − 0.5)
u' = sign(u)·|u|^p，p = 1/(1+c)，c ∈ [−0.99, 1]
v  = (u' + 1)/2 → clip[0,1] → ×255 → uint8
```

- `c=0` 线性；正=增对比（暗更暗、亮更亮）；负=减对比（压向中灰）；
- 锚点保持：0→0、0.5→0.5、1→1；
- **不再使用输出 gamma 编码**（曝光正确性由三锚点保证）；
- 高光软肩已移除（历史实现中 PCHIP 已把 pos 夹到 [0,1]，软肩永不触发，
  且最终 clip 使其无效；过曝收口由特性曲线肩部 + 白端截断负责）。

### 3.3 扫描元数据（`FILM_PROFILES`，2026-08-29 纯物理版标定）

锚点均为密度域（黑白即特性曲线密度本身；彩负/彩正由 `D=−log10(scan)` 定义）：

| 胶片 | kind | black | gray | white |
|---|---|---|---|---|
| 5213 | color_negative | [0.19303, 0.58123, 0.86273] | [0.70097, 1.33770, 1.67244] | [0.97792, 1.73950, 2.14993] |
| gold200 | color_negative | [0.23908, 0.62761, 0.96540] | [0.53693, 1.15090, 1.55571] | [0.78872, 1.55689, 2.13059] |
| provia100f | color_positive | [3.43603, 3.80905, 4.02428] | [0.93828, 1.01484, 1.10056] | [0.13816, 0.14014, 0.14528] |
| hp5 | bw_negative | 0.12670 | 0.78990 | 1.30260 |

- 标定方法：把 `0,0,0` / `E_mid=1` / `E_mid=6.24` 输入走完整管线，实测密度后写死；
- 白锚是**胶片参考**（正片即 D-min 端），不是传感器参考——传感器饱和在
  E_mid 中的位置随 BaselineExposure 变化，锚点因此保持静态；
- 管线改动（曝光轴、特性曲线、颗粒、光谱）后**必须重新标定**，并更新注释日期。

### 3.4 16bit 原片导出

```
neg16 = clip(scan, 0, 1) × 65535（uint16，RGB→BGR 存 TIFF）
```

彩负导出为负像、彩正导出为正像（无反转、无显示编码），供自行调色/研究。

## 4. 三类胶片的构建差异

### 4.1 彩色负片（5213 / Gold 200 蓝本）

**数据需求（五类，全按 R/G/B 三层）：**

| 数据 | 轴定义 | 必填 | 代理示例 |
|---|---|---|---|
| 感光特性曲线 | X=相对对数曝光，Y=Status M 密度 | 必填 | — |
| RMS 颗粒度曲线 | X=对数曝光，Y=σD | 必填 | Gold 用 5213 形状 ×1.9（C200 样张统计估测） |
| MTF 曲线 | X=空间频率(cyc/mm)，Y=反应率% | 必填 | 无分层→同级卷三层共用（Gold 用 Superia 200） |
| 光谱灵敏度/吸收 | X=波长(nm)，Y=感光对数值 | 必填 | — |
| 染料光谱密度 | X=波长(nm)，Y=漫射光谱密度 | 必填 | 只有中灰+D-min→参考卷形状数学修正 |

**管线特征：**

- 光谱重建 → PSF → logH → 特性曲线（正斜率）→ 密度域颗粒（σ 按 logH）→
  染料堆叠 → 负像透光率 scan；
- 第三段：`D=−log10(scan)`（色罩在密度域是加法常数），三锚点 PCHIP：
  黑端去色罩、中灰校色平衡、白端锚定白场；
- 输出端无需逐通道截止（三锚点已保证），白端静态截断。

### 4.2 彩色正片（Provia 100F 蓝本）

**与彩负的本质区别：正片是直接观看介质，没有“反转 + 校色 + 去色罩”概念。**

**数据需求**与彩负相同（特性曲线、颗粒度、MTF、光谱灵敏度、染料光谱），
但特性曲线为**负斜率**（高曝光 → 低密度 → D-min）。

**管线特征：**

- 光谱重建 → PSF → logH → 特性曲线（负斜率）→ 密度域颗粒 →
  染料堆叠 → **正像透光率 scan**（无需反转）；
- 第三段仍走三锚点 PCHIP，但锚点自动按密度排序（black > gray > white），
  数学上与彩负统一：0,0,0 → 黑、E_mid=1 → 118、饱和 → 白；
- 忠实保留 D-min 灰雾（正片色彩是它自己的，无校色）；
- 16bit 导出为正像。

### 4.3 黑白负片（HP5 蓝本）

黑白是彩负的单层简化：**无三层染料、无染料堆叠、无 CIE 扫描、无色罩**。

**数据需求（单层）：**

| 数据 | 轴定义 | 说明 |
|---|---|---|
| 感光特性曲线 | X=相对对数曝光，Y=密度 | 必填 |
| RMS 颗粒度曲线 | X=**净密度**，Y=σD | 黑白 rms 曲线 X 轴是密度，直接密度域查表 |
| MTF 曲线 | X=空间频率，Y=反应率% | 必填（可代理） |
| 光谱灵敏度 | X=波长，Y=相对感光度 | 必填（同样走光谱重建，单通道） |

**管线特征：**

- 光谱重建（(4,1) 矩阵）→ PSF（单层）→ logH → 特性曲线 →
  密度域颗粒（σ 按**密度**查表）→ 直接输出 density；
- 第三段：单通道密度域三锚点 PCHIP；
- 无“扫描色罩”问题，锚点即密度三锚点。

## 5. 数据获取与归档规范

### 5.1 文档库目录约定

```
胶片技术文档/
└── <厂商>/
    ├── 黑白/ <型号>/
    ├── 彩负/ <型号>/
    ├── 正片/ <型号>/
    └── 工艺与技术资料/
```

- 电影卷用编号作为型号通用名（如 `5213 VISION3 200T（电影）`）；
- 同型号文档放同一文件夹；缺中文文档的补一份中文翻译 PDF；
- 每个型号目录维护一份型号列表（名称/类型/ISO/数据状态）。

### 5.2 描点规范

- 曲线转折处加密、平直段稀疏；**原始描点单独存 `*_raw.csv` 归档，绝不覆盖**；
- 每份描点记录来源文档、页码、描点日期；
- 同一曲线不同显影条件只保留建模目标的一条，并在 README 注明条件
  （如 HP5 为 ILFOTEC HC 显影）；
- 曲线可以先图像理解精读，再与描点交叉验证。

### 5.3 插值与归档

- 统一 **PCHIP 保型插值**（不过冲、保形状），网格加密到可直接查表的稠密轴；
- **所有查表轴（特性曲线、颗粒度）统一到严格均匀网格**
  （float64，dx 偏差 <1e-12），运行时走免二分快速插值；
- 波长轴统一 400–700nm、5nm 间隔、61 点（对齐 `Spectral/cie_data.py`）；
- 每套数据存两份：插值后 `.csv`（人读归档）+ `.npz`（运行时唯一数据源）；
- 数据目录写 `README.md`：来源、描点日期、插值方式、代理说明、显影条件。

### 5.4 缺失数据的代理策略

按“定位最接近的胶片”借用，**每项代理必须写入 README 并标注可信度**：

- MTF 无分层 → 同级胶片曲线三层共用；
- 颗粒度无实测曲线 → 同级卷的形状 + 放缩系数（数值可由样张平场统计估测）；
- 染料逐层缺失（只有中灰+D-min）→ 参考卷染料形状数学修正：
  ① 幅度拟合 → ② 逐波长残差按染料贡献占比回填 → ③ Savitzky-Golay 平滑；
- 拿到真实数据后替换代理，并重新标定锚点。

### 5.5 代码结构

```
Films/<name>/
├── <name>.py          # 模型主文件：管线 + REF_LOG_E/锚点/缓存常量
├── <name>_data.py     # 数据加载器（只读 npz，带缓存 + 均匀网格标记）
└── data/              # raw + 插值 csv + npz + README + 运行缓存
```

注册步骤：

1. `Films/<name>/` 建目录，数据落盘；
2. `<name>_data.py` 加载特性曲线/颗粒度/MTF/染料；
3. `<name>.py` 实现 `process_scan(lux_r, lux_g, lux_b, grain_ss, exposure_offset)`
   与 `process(...)` 便捷入口；
4. `Spectral/migrate.py` + `reconstruct.py::_SENSITIVITY_CSV` 注册光谱灵敏度，
   递增光谱重建缓存版本；
5. `Scanner/scanner.py::FILM_PROFILES` 登记 kind + 三锚点（先跑标定）；
6. `main.py` 胶片下拉框 + `selftest.py` 注册烟测。

## 6. 曝光标定（统一标准）

### 6.1 输入侧（相机/图源）

ISO 12232 SOS 灰点：`H_gray/H_sat = 10/78 ≈ 0.1282`，配合相机
`BaselineExposure` 让“相机正确曝光”恒落在 `E_mid=1`（见 §1.2）。

### 6.2 胶片侧（数据表灰点锚）

```
REF_LOG_E = log10(K / EI)，K = 12.5（静照测光常数），EI = 标称 ISO
```

| 胶片 | 类型 | EI | REF_LOG_E |
|---|---|---|---|
| 5213（VISION3 200T） | 彩负 | 200 | −1.20412 |
| Gold 200 | 彩负 | 200 | −1.20412 |
| Provia 100F | 彩正 | 100 | −0.90309 |
| HP5 Plus | 黑白 | 400 | −1.50515 |

说明：

- `E_mid=1 → logH = REF_LOG_E`，即数据表灰点（如 Provia 三层 D=0.9）落在
  stop 0；数据表“相对对数曝光量”轴整体平移对齐到这条绝对物理轴；
- 输入侧 10/78 与胶片侧 K/EI 是**两套各自自洽的约定**：前者管相机灰点
  相对饱和的位置，后者管数据表灰点在绝对 logH 轴上的位置；
  两者在 `E_mid=1` 处对接，不必强行统一成同一个常数；
- 统一轴后输出亮度会变（如 5213 当年因此亮约 0.27 档），是标准化代价，不是 bug。

### 6.3 三锚点标定

```
黑 = 0,0,0 输入走完整管线的密度（片基/未曝光）
灰 = E_mid=1 输入走完整管线的密度（18% 灰）
白 = E_mid=6.24 输入走完整管线的密度（白锚标定输入，胶片高光端）
```

- 写死为 `FILM_PROFILES` 常量，注释注明标定条件与日期；
- 改曝光轴、特性曲线、光谱、颗粒或扫描逻辑后**必须重新标定**；
- 密度域减橙罩方案已废弃（黑端去色罩由三锚点黑锚承担）。

## 7. 性能基线

13.7MP（3024×4536）稳态实测（颗粒 1x，缓存命中）：

| 模型 | 总耗时 |
|---|---|
| 彩负 / 彩正 | ≈ 5 s |
| 黑白 | ≈ 0.8 s |

单阶段参考（3.1MP 老基线，按面积比例约 4.4× 折算到 13.7MP）：

| 阶段 | 耗时（3.1MP） |
|---|---|
| 光谱迁移 3×3 矩阵 | ~40 ms |
| PSF 高斯堆卷积 | ~80 ms |
| 对数曝光 + 特性曲线（均匀网格） | ~75 ms |
| 颗粒 ss=1 / ss=2 | ~0.3 s / ~1.2 s |
| 染料堆叠 + 客观扫描 | ~0.6 s |
| 冷启动（PSF/颗粒缓存命中） | <0.1 s |

优化原则：**任何性能优化都必须与优化前基线逐像素对比，>1 灰阶占比为 0**
（数值不可识别的差异才允许；这是 A+B+C 验证的既定结论）。
