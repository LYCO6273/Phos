# 胶片标准构建流程（0.3.1 起）

> 本文档定义从技术文档（datasheet）到可运行胶片模型的标准流程。
> 彩负以 5213 / Gold 200 为蓝本，黑白负片以 HP5 为蓝本。
> 原则只有三条：**数据从文档来、缺失找同级代理、所有轴统一到绝对物理标尺**。

---

## 一、彩色负片标准构建流程

### 1. 数据获取与描点

一套彩负需要五类数据，全部按 R/G/B 三层记录（层映射：R=红感光/青染料，
G=绿感光/品红染料，B=蓝感光/黄染料）：

| 数据 | 轴定义 | 用途 | 必填 |
|---|---|---|---|
| 感光特性曲线 | X=相对对数曝光，Y=Status M 密度 | 曝光→密度的核心映射 | 必填 |
| RMS 颗粒度曲线 | X=对数曝光，Y=σD | 颗粒大小随曝光变化 | 必填（可用代理） |
| MTF 曲线 | X=空间频率(cyc/mm)，Y=反应率% | 拟合 PSF 扩散核 | 必填（可用代理） |
| 光谱灵敏度/吸收光谱 | X=波长(nm)，Y=感光对数值 | 光谱输入迁移 | 必填 |
| 染料光谱密度 | X=波长(nm)，Y=漫射光谱密度 | 染料堆叠+扫描 | 必填（中灰+D-min） |

描点规范：
- 曲线转折处加密、平直段稀疏；**原始描点单独存 `_raw.csv` 归档，绝不覆盖**
- 每份描点记录来源文档、页码、描点日期
- 同一曲线不同显影条件（不同显影液/时间）只保留建模目标的那一条，并在 README 注明条件

### 2. 插值与归档

- 统一 **PCHIP 保型插值**（不过冲、保形状），网格加密到可直接查表的稠密轴
- **所有查表轴（特性曲线、颗粒度）统一插值到严格均匀网格**（float64 存储，
  dx 偏差 <1e-12），模型走免二分快速插值；非均匀网格必须回退 `np.interp` 兜底
- 特性曲线两端按渐近处理（D-min / D-max = 网格两端值）
- 波长轴对齐 Spectral 模块：400–700/800nm，61 点
- 每套数据存两份：插值后 `.csv`（人读归档）+ `.npz`（运行时唯一数据源）
- 数据目录写 `README.md`：来源、描点日期、插值方式、代理说明、显影条件

### 3. 缺失数据的代理策略

按"定位最接近的胶片"借用：
- MTF：无分层 → 用同级胶片的曲线三层共用（Gold 用了 Superia 200）
- 颗粒度：没有实测 rms 曲线 → 用同级卷的形状 + 放缩系数
  （Gold 用 5213 形状 × 1.9，由 C200 样张平场统计估测）
- 染料逐层：只有中灰+D-min → 用参考卷染料形状做数学修正：
  ① 幅度拟合 → ② 逐波长残差按染料贡献占比回填 → ③ Savitzky-Golay 平滑
- 每项代理必须写进 README，注明来源与可信度，拿到真数据后替换

### 4. 代码结构

每个新彩负在 `Films/` 下建独立目录（电影卷用编号如 `5213`，消费卷用型号名如 `Gold200`）：

```
Films/<name>/
├── <name>.py          # 模型主文件：管线 + 曝光/锚点/伽马常量
├── <name>_data.py     # 数据加载器（只读 npz，带缓存 + logE_uniform 标记）
└── data/              # raw + 插值 csv + npz + README + 运行缓存
```

另外在 `Spectral/migrate.py` 注册 `film="<name>"`，把该卷光谱灵敏度接进光谱迁移。

### 5. 模型管线（固定顺序，不可乱）

1. **光谱输入（固定开启）**：线性 RGB → CIE-RGB 色匹配函数伪发射源 →
   实测灵敏度吸收积分，得到三层有效曝光
2. **PSF 光扩散**：核心高斯 + K0 扩散晕 − 邻界项；核参数由 MTF 频域拟合标定，
   曝光量只影响强度线性增益；拟合结果落盘缓存（带 MTF 指纹自动失效）
3. **对数曝光工作区**：`logH = log10(E) + CAL + offset·log10(2)`
4. **特性曲线查表**：三层各查各的 → Status M 密度（均匀网格快速插值，两端夹紧）
5. **密度域颗粒**：白噪声 → Cholesky 层间相关（ρ=0.5）→ sign·χ² 伽马聚簇 →
   可分离高斯组合赋形 → 可选 2x 超采样 → 48µm 孔径闭环标定（Monte Carlo，
   结果落盘缓存）
6. **染料堆叠 + 客观 CIE-RGB 扫描**：`D(λ) = Σ(净层密度×归一化染料光谱) + Dmin(λ)`，
   `T = exp(-ln10·D)`，`XYZ = Σ T·D65·CMF·Δλ`（一次矩阵乘）→ 线性 sRGB 负片读数
7. **反转输出**：对数密度域固定锚点（0,0,0→黑端，1,1,1→白端），
   `pos = (D − D黑端)/(D白端 − D黑端)`，叠胶片专用 gamma → uint8

### 6. 曝光标定（统一标准）

所有胶片统一：`K = 12.5`（静照测光常数）、`EI = 标称 ISO` →

> **logH_gray = log10(K / EI)**

ISO 200 → −1.20412；ISO 400 → −1.50515；ISO 100 → −1.90309。
把数据手册"相对对数曝光量"的灰点对齐到这条绝对物理轴：数据轴整体平移，
`REF_LOG_E = logH_gray`。注意统一轴后输出亮度会变（5213 当年因此亮约 0.27 档），
这是标准化代价，不是 bug。

### 7. 黑白点标定

- **黑端** = 0,0,0 输入走完完整管线的扫描值（片基/未曝光）
- **白端** = 1,1,1 输入走完完整管线的扫描值（场景白）
- 写死为标定常量，注释注明标定条件与日期；改曝光轴或数据后必须重新标定
- 反转锚点与扫描固定用带片基色罩路径（密度域减橙罩方案已废弃）

### 8. 输出伽马

按胶片标定写进 `OUT_GAMMA`（Gold 200=1.4、5213=1.7），UI 默认值随胶片切换。

### 9. 验证清单

- selftest：CIE 常量、默认调用等价显式参数、纯红/纯蓝光谱驱动、
  MTF→PSF 拟合误差、颗粒孔径闭环（1x/2x）、超采样差异、曝光/伽马响应
- 端到端锚点：0,0,0→输出黑、1,1,1→输出白
- 数值等价（性能优化后）：与优化前基线逐像素对比，>1 灰阶占比必须为 0
- 实拍样张：最终以真实样张的影调/色彩/颗粒观感验收，代理参数用样张统计修正

### 10. 性能基线（3.1MP，稳态）

- 光谱迁移 3×3 矩阵：~40ms
- PSF 高斯堆：~80ms
- 对数曝光+特性曲线（均匀网格插值）：~75ms
- 颗粒 ss=1 / ss=2：~0.3s / ~1.2s
- 染料堆叠+扫描（matmul + exp）：~0.6s
- 冷启动（PSF/颗粒缓存命中）：<0.1s

## 二、黑白负片标准构建流程（HP5 蓝本）

黑白负片是彩负的单层简化：**没有三层染料、没有光谱迁移、没有染料堆叠+扫描**。
核心仍是"曝光 → 特性曲线 → 密度域颗粒 → 反转"。

### 1. 数据

| 数据 | 轴定义 | 说明 |
|---|---|---|
| 感光特性曲线 | X=相对对数曝光，Y=密度 | 单层，必填 |
| RMS 颗粒度曲线 | X=**密度**，Y=σD（rms×1000） | 黑白 rms 曲线 X 轴通常是密度，直接密度域查表 |
| MTF 曲线 | X=空间频率，Y=反应率% | 单层，必填（可代理） |
| 光谱灵敏度 | X=波长，Y=相对感光度 | 必填；黑白模型同样走光谱输入迁移（单通道） |

黑白颗粒度**不需要**转成 logE 轴：颗粒在密度域直接按密度查 σ-D 曲线，
比彩负（logE 轴）反而更直接。

### 2. 代码结构

同彩负：`Films/<name>/` 下 `<name>.py` + `<name>_data.py` + `data/`。
数据同样统一插值到均匀网格、npz+csv 双归档、README 记录来源。

### 3. 管线（单层）

1. **光谱输入（固定）**：CIE-RGB 色匹配函数伪发射源 → 实测灵敏度吸收积分（单通道，与彩负同一思路）
2. **PSF 光扩散**：与彩负相同（MTF 拟合，单层即可）
3. **对数曝光**：`logH = log10(L) + CAL + offset·log10(2)`
4. **特性曲线**：logH → 密度（均匀网格快速插值）
5. **密度域颗粒**：与彩负相同算法，σ 按**密度**查表（颗粒度曲线 X 轴=密度）
6. **反转**：单通道固定锚点——黑端=片基 D-min 扫描值，白端=场景白扫描值；
   `pos = (D − D黑)/(D白 − D黑)`，叠 gamma → uint8

黑白没有"负片扫描色罩"问题，反转锚点即两端截止；仍按 0,0,0 / 1,1,1
输入走管线预计算并写死为常量。

### 4. 曝光标定

与彩负完全相同：`logH_gray = log10(K/EI)`，K=12.5，EI=标称 ISO。
HP5 为 ISO 400 → **logH_gray = −1.50515**。
